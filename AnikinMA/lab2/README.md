# Практическая работа №2
# Детектирование объектов на изображениях с использованием библиотеки OpenCV


## Исходные данные

В работе использованы:
- набор кадров видео `imgs_MOV03478`;
- файл разметки `mov03478.txt`.

Файл разметки содержит:
- номер кадра;
- название класса;
- координаты ограничивающего прямоугольника.

В разметке присутствуют классы:
- CAR
- BUS

## Используемые средства

- Язык программирования: Python
- Библиотека: OpenCV (модуль cv2.dnn)
- Формат моделей: ONNX

## Используемые модели

В работе применены три модели детектирования:

1. YOLOv8n
2. YOLOv5nu
3. YOLOX-tiny

Все модели подключены через модуль OpenCV DNN и работают в формате ONNX.

## Предварительная обработка изображений

Перед подачей изображения на вход модели выполняются:
- изменение размера изображения до фиксированного разрешения;
- сохранение пропорций изображения (letterbox);
- нормализация значений пикселей;
- преобразование изображения в формат blob.

## Постобработка результатов

После получения результатов работы модели выполняются:

1. Преобразование координат прямоугольников к размеру исходного изображения.
2. Отбрасывание всех классов, кроме транспортных средств.
3. Фильтрация по порогу уверенности.
4. Применение алгоритма подавления немаксимумов (NMS).

## Метрики качества

Для оценки качества используются следующие метрики.

True Positive Rate (TPR):

TPR = TP / (TP + FN)

Показывает долю корректно обнаруженных объектов среди всех объектов разметки.

False Discovery Rate (FDR):

FDR = FP / (TP + FP)

Показывает долю ложных срабатываний среди всех предсказаний модели.

## Экспериментальные результаты

Оценка проводилась на первых 500 кадрах последовательности.

Модель YOLOv8n (confidence = 0.20):
TPR = 0.978  
FDR = 0.314  

Модель YOLOv5nu (confidence = 0.20):
TPR = 0.967  
FDR = 0.281  

Модель YOLOX-tiny (confidence = 0.45):
TPR = 0.897  
FDR = 0.059  

Модель YOLOv8n продемонстрировала наибольшую полноту детектирования.

Модель YOLOv5nu показала наиболее сбалансированное соотношение между полнотой и количеством ложных срабатываний.

Модель YOLOX-tiny обеспечивает минимальное количество ложных срабатываний, однако уступает по полноте обнаружения объектов.

Выбор модели зависит от требований задачи:
- приоритет полноты — YOLOv8n;
- приоритет минимизации ложных срабатываний — YOLOX-tiny;
- компромиссное решение — YOLOv5nu.

## Запуск программы

Примеры запуска:

python main.py --model yolov8n_onnx --conf 0.20 --show  
python main.py --model yolov5n_onnx --conf 0.20 --show  
python main.py --model yolox_tiny_onnx --conf 0.45 --show
