# Практическая работа №3. Классификация изображений с использованием библиотеки OpenCV

## Часть 1. Алгоритм "Мешок слов" (BoW)

### Описание метода

Алгоритм включает следующие этапы:

1. Извлечение локальных признаков с помощью SIFT.
2. Формирование словаря визуальных слов методом k-means.
3. Представление изображения в виде гистограммы визуальных слов.
4. Классификация гистограмм с помощью метода опорных векторов (SVM).

Каждое изображение представляется как вектор фиксированной длины k, где k — размер словаря.

### Параметры эксперимента

Детектор/дескриптор: SIFT  
Размер словаря: k = 256  
Классификатор: SVM (linear kernel)  
Нормализация гистограммы: L2  

Команда запуска:

python main.py --data_dir . --split_train train.txt --mode train_test --algo bow --detector sift --k 256 --svm_kernel linear

Время обучения: 143.16 секунд.

### Результаты (BoW)

Accuracy: 0.9773

Confusion matrix (rows=true, cols=pred):

[[39  0  0]
 [ 0 29  0]
 [ 2  0 18]]

Метод показал высокую точность классификации. Ошибки наблюдаются только для двух изображений класса Архангельский собор.

## Часть 2. Нейросетевая классификация (Transfer Learning)

### Описание метода

Использована предобученная модель MobileNetV3 Small из библиотеки torchvision.

Выполнены следующие шаги:

1. Загрузка предобученной модели.
2. Замена последнего классификационного слоя на слой с тремя выходами.
3. Заморозка базовой части сети (backbone).
4. Обучение классификационного слоя на обучающей выборке.

Использование переноса обучения позволяет эффективно обучать модель даже на сравнительно небольшом наборе данных.

### Параметры эксперимента

Backbone: MobileNetV3 Small  
Размер входного изображения: 192x192  
Количество эпох: 5  
Batch size: 8  
Learning rate: 0.001  
Freeze backbone: 1  

Команда запуска:

python main.py --data_dir . --split_train train.txt --mode train_test --algo nn --backbone mobilenet_v3_small --epochs 5 --batch_size 8 --img_size 192 --freeze 1

### Результаты (NN)

Accuracy: 0.9886

Confusion matrix (rows=true, cols=pred):

[[39  0  0]
 [ 0 29  0]
 [ 1  0 19]]

Нейросетевая модель показала более высокую точность по сравнению с методом BoW. Ошибка наблюдается только для одного изображения.

## Сравнение методов

BoW (SIFT + SVM): Accuracy = 0.9773  
MobileNetV3 (Transfer Learning): Accuracy = 0.9886  

Нейросетевой подход продемонстрировал наилучшее качество классификации на тестовой выборке.

Оба метода показали высокое качество, при этом нейросетевая модель продемонстрировала наилучший результат по метрике accuracy.
